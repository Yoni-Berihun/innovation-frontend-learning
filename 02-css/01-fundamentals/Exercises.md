# Exercises: CSS Fundamentals

> Practice the essential CSS skills covered in the fundamentals module.

---

## 🟢 Easy Exercises

### Exercise 1.1: Style a Simple Page
**Objective:** Apply CSS to basic HTML elements.

**Instructions:**
- Create an HTML page with a heading, paragraph, and link.
- Create `styles.css` and link it.
- Set a background color for the page.
- Change the heading color.
- Add spacing with padding and margin.

### Exercise 1.2: Style Text and Links
**Objective:** Practice typography and text styling.

**Instructions:**
- Add a paragraph and a list.
- Set `font-family` and `line-height` for body text.
- Use a class to style one paragraph differently.
- Style the link color and hover state.

---

## 🟡 Medium Exercises

### Exercise 2.1: Build a Profile Card
**Objective:** Practice box model and layout fundamentals.

**Instructions:**
- Create a card with an image, heading, and description.
- Add padding, border, and border-radius.
- Use `box-shadow` for a subtle shadow.
- Center the card on the page.

### Exercise 2.2: Create a Feature Section
**Objective:** Use classes and spacing rules.

**Instructions:**
- Create three feature boxes.
- Add a title and description to each.
- Use CSS classes to style all boxes.
- Add consistent spacing between boxes.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Build a Landing Page Section
**Objective:** Combine typography, colors, and layout.

**Instructions:**
- Create a section with a heading, paragraph, and button.
- Use a background gradient or image.
- Style the button with padding, background color, and hover effect.
- Add a secondary text block below the main content.

### Exercise 3.2: Create a Small Info Card Layout
**Objective:** Practice advanced CSS structure.

**Instructions:**
- Create a container with two cards.
- Use classes to style card background, border, and spacing.
- Add a title, list, and button in each card.
- Optionally use `inline-block` or `display: flex` for card layout.
