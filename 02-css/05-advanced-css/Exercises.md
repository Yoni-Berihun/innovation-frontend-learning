# Exercises: Advanced CSS

> Practice advanced CSS features and polish real web page components.

---

## 🟢 Easy Exercises

### Exercise 1.1: Use CSS Variables
**Objective:** Create reusable theme values.

**Instructions:**
- Define variables for primary color, text color, and spacing.
- Use those variables in your styles.
- Change one variable to see the theme update.

### Exercise 1.2: Add a Hover Transition
**Objective:** Use transitions to improve interaction.

**Instructions:**
- Create a button.
- Add a `transition` on `background-color` and `transform`.
- Add a hover effect that changes color and moves the button slightly.

---

## 🟡 Medium Exercises

### Exercise 2.1: Build a Card Animation
**Objective:** Add entrance animation to card elements.

**Instructions:**
- Create 3 cards.
- Use a `@keyframes` animation to fade them in.
- Add a slight hover transform to each card.

### Exercise 2.2: Build a Dark Mode Toggle
**Objective:** Use CSS variables and a class for theming.

**Instructions:**
- Define light and dark theme variables.
- Add a CSS class like `.dark-mode`.
- Style the page for both themes.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Build a Stylish Pricing Section
**Objective:** Create a polished pricing component.

**Instructions:**
- Use pseudo-elements for decorative shapes.
- Use `::before` or `::after` to add accents.
- Add a `hover` effect with transform and shadow.
- Use variables for colors and spacing.

### Exercise 3.2: Build a Responsive Animated Gallery
**Objective:** Combine advanced CSS with responsive layout.

**Instructions:**
- Create a gallery of images.
- Add hover states and animations.
- Use responsive Grid and flex rules.
- Include captions and decorative pseudo-elements.
