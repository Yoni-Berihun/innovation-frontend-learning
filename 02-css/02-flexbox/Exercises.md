# Exercises: Flexbox

> Practice common Flexbox layout patterns and responsive design.

---

## 🟢 Easy Exercises

### Exercise 1.1: Center a Box
**Objective:** Use Flexbox to center content.

**Instructions:**
- Create a container with a box inside.
- Use `display: flex` on the container.
- Center the box both horizontally and vertically.

### Exercise 1.2: Build a Horizontal Menu
**Objective:** Create a navigation bar with Flexbox.

**Instructions:**
- Create a nav with 4 links.
- Use Flexbox to place links in a row.
- Add spacing using `gap` or `margin`.

---

## 🟡 Medium Exercises

### Exercise 2.1: Create a Responsive Card Row
**Objective:** Build a row of cards that wraps on smaller screens.

**Instructions:**
- Build 3 cards in a row.
- Use `flex-wrap: wrap` and `flex: 1 1 250px`.
- Add card padding, border, and background color.

### Exercise 2.2: Build a Feature Section
**Objective:** Create a responsive feature section.

**Instructions:**
- Use a container with 3 feature items.
- Align item content with `align-items`.
- Add a title and description for each item.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Create a Hero Layout
**Objective:** Build a hero section with two columns.

**Instructions:**
- Use Flexbox for text on one side and an image on the other.
- Make the layout wrap into one column on smaller screens.
- Add spacing and align the content vertically.

### Exercise 3.2: Build a Responsive Footer
**Objective:** Create a footer with multiple groups.

**Instructions:**
- Create 3 columns of footer links.
- Use Flexbox with `flex-wrap`.
- On smaller screens, stack the groups vertically.
