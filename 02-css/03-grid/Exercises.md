# Exercises: CSS Grid

> Practice CSS Grid layouts and responsive grid techniques.

---

## 🟢 Easy Exercises

### Exercise 1.1: Create a Simple Grid
**Objective:** Build a basic grid layout.

**Instructions:**
- Create a grid container with 6 items.
- Use `grid-template-columns: repeat(3, 1fr)`.
- Add gaps between items.

### Exercise 1.2: Build a Sidebar Layout
**Objective:** Use columns and rows.

**Instructions:**
- Create a layout with sidebar and main content.
- Use `grid-template-columns: 200px 1fr`.
- Add a header row and footer row if desired.

---

## 🟡 Medium Exercises

### Exercise 2.1: Create a Responsive Card Grid
**Objective:** Build a grid of cards that adapts to screen size.

**Instructions:**
- Use `repeat(auto-fit, minmax(240px, 1fr))`.
- Add 8 cards with titles and descriptions.
- Add padding, border, and background color.

### Exercise 2.2: Build a Dashboard Layout
**Objective:** Use grid areas for layout.

**Instructions:**
- Create header, sidebar, main, and footer areas.
- Use `grid-template-areas`.
- Place each section into the correct grid area.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Build a Magazine Layout
**Objective:** Create a complex multi-column layout.

**Instructions:**
- Create a layout with featured article, side stories, and footer.
- Use `grid-template-columns` and `grid-template-rows`.
- Place items using `grid-column` and `grid-row`.

### Exercise 3.2: Build a Responsive Gallery
**Objective:** Practice complex grid placement.

**Instructions:**
- Create a gallery of 9 images.
- Use a mix of small and large items.
- Position a featured image using `grid-column: span 2`.
- Make the gallery responsive with `auto-fit`.
