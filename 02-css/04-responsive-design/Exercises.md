# Exercises: Responsive Design

> Practice responsive layout patterns and mobile-first CSS.

---

## 🟢 Easy Exercises

### Exercise 1.1: Make a Page Mobile-Friendly
**Objective:** Add responsive styles using a media query.

**Instructions:**
- Create a page with a hero section and cards.
- Use a single-column layout by default.
- At `min-width: 768px`, switch to two columns.

### Exercise 1.2: Create a Responsive Image
**Objective:** Use fluid images.

**Instructions:**
- Add an image to a page.
- Use `max-width: 100%` and `height: auto`.
- Add a caption below the image.

---

## 🟡 Medium Exercises

### Exercise 2.1: Build a Responsive Feature Section
**Objective:** Create a section that adapts to screen width.

**Instructions:**
- Use `display: grid` or Flexbox.
- Start with one column on small screens.
- Add a media query to show 2 or 3 columns on larger screens.

### Exercise 2.2: Create a Responsive Navigation Bar
**Objective:** Build a mobile-friendly menu.

**Instructions:**
- Create a nav with links.
- Stack links vertically on small screens.
- Display links in a row on medium and larger screens.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Build a Mobile-First Landing Page
**Objective:** Use responsive layout, typography, and spacing.

**Instructions:**
- Build a hero section, features, and footer.
- Use fluid typography with `clamp()`.
- Use media queries to change layout at 768px and 1024px.

### Exercise 3.2: Create a Responsive Pricing Table
**Objective:** Build a pricing section that adapts.

**Instructions:**
- Create 3 pricing cards.
- Use a stacked layout on mobile.
- On larger screens, display cards in a row.
- Add spacing and hover styles.
