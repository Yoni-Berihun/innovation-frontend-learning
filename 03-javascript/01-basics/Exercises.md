# Exercises: JavaScript Basics

> Practice the essential JavaScript concepts from the basics module.

---

## 🟢 Easy Exercises

### Exercise 1.1: Add Numbers
**Objective:** Practice variables and arithmetic.

**Instructions:**
- Create a JavaScript file or a script block.
- Create two number variables.
- Add them together.
- Show the result using `console.log()`.

### Exercise 1.2: Favorite Food
**Objective:** Practice strings and variables.

**Instructions:**
- Create a variable for your name.
- Create a variable for your favorite food.
- Use a template string to print a sentence like `My name is ... and I love ...`.

---

## 🟡 Medium Exercises

### Exercise 2.1: Grade Message
**Objective:** Use `if` and `else`.

**Instructions:**
- Create a variable `score`.
- If score is 90 or higher, print `Excellent!`.
- If score is 70 or higher, print `Good job!`.
- Otherwise, print `Keep practicing!`.

### Exercise 2.2: Repeat with a Loop
**Objective:** Use a loop to print numbers.

**Instructions:**
- Use a `for` loop to print numbers from 1 to 10.
- Use a `while` loop to print even numbers from 2 to 10.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Create a Simple Function
**Objective:** Build a reusable function.

**Instructions:**
- Create a function `square(number)` that returns the number squared.
- Call the function for 2, 3, and 5.
- Print the results.

### Exercise 3.2: Build a Person Object
**Objective:** Use objects to store data.

**Instructions:**
- Create an object called `person` with `name`, `age`, and `hobby`.
- Add a method `introduce()` that returns a sentence.
- Call `person.introduce()` and print it.
