# Exercises: ES6+ Modern JavaScript

> Practice modern JavaScript features and write cleaner code.

---

## 🟢 Easy Exercises

### Exercise 1.1: Use Template Strings
**Objective:** Practice template literals.

**Instructions:**
- Create variables `name` and `city`.
- Use a template string to print `My name is ... and I live in ...`.

### Exercise 1.2: Use `const` and `let`
**Objective:** Practice variable rules.

**Instructions:**
- Create a `const` value for your favorite color.
- Create a `let` value for a number and increase it.

---

## 🟡 Medium Exercises

### Exercise 2.1: Use Arrow Functions
**Objective:** Convert functions to arrow functions.

**Instructions:**
- Create a function that doubles a number.
- Convert it to an arrow function.
- Test it with several values.

### Exercise 2.2: Use Destructuring
**Objective:** Extract values from arrays and objects.

**Instructions:**
- Create an object with `title`, `author`, and `year`.
- Use destructuring to store these values in separate variables.
- Create an array of three colors and use array destructuring.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Use `map` and `filter`
**Objective:** Transform arrays with modern methods.

**Instructions:**
- Create an array of numbers.
- Use `map` to create a new array of doubled values.
- Use `filter` to keep only even numbers.

### Exercise 3.2: Create a Class
**Objective:** Build a simple JavaScript class.

**Instructions:**
- Create a `Product` class with `name` and `price`.
- Add a method `discount(amount)` that returns the price after discount.
- Create a product and print the discounted price.
