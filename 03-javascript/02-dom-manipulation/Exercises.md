# Exercises: DOM Manipulation

> Practice JavaScript DOM skills by building interactive page behavior.

---

## 🟢 Easy Exercises

### Exercise 1.1: Change Page Text
**Objective:** Select and update an element.

**Instructions:**
- Create an HTML page with a heading and paragraph.
- Use JavaScript to change the heading text when the page loads.

### Exercise 1.2: Toggle a Class
**Objective:** Add or remove a CSS class with JavaScript.

**Instructions:**
- Add a button and a box element.
- When the button is clicked, toggle a class on the box.
- Use CSS to make the box visible or hidden based on the class.

---

## 🟡 Medium Exercises

### Exercise 2.1: Build a Click Counter
**Objective:** Update the page when a button is clicked.

**Instructions:**
- Add a paragraph showing a number.
- Add a button labeled `+`.
- Increase the number each time the button is clicked.

### Exercise 2.2: Show Input Value
**Objective:** Read text from an input and display it.

**Instructions:**
- Add a text input and a button.
- When the button is clicked, show the input value in a paragraph.
- Clear the input after showing the value.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Build a To-Do List
**Objective:** Add items to a list using JavaScript.

**Instructions:**
- Add an input, a button, and an empty list.
- When the button is clicked, create a new list item.
- Clear the input after adding the item.

### Exercise 3.2: Create a Tab Switcher
**Objective:** Use DOM classes to show and hide sections.

**Instructions:**
- Create 3 tabs and 3 content sections.
- When a tab is clicked, show the matching section and hide the others.
- Use a class like `active` to style the selected tab.
