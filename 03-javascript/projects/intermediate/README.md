# Intermediate JavaScript Projects

> Build richer interactions and start using modern JavaScript patterns.

## Project 1: To-Do List

**What to build:**
- A form to add tasks
- A list of tasks shown on the page
- Buttons to mark tasks complete or remove them

**What you practice:**
- DOM creation and updates
- Event delegation
- Arrays and object data

## Project 2: Tabbed Content

**What to build:**
- A page with tab buttons and content sections
- Clicking a tab shows the matching section
- Highlight the active tab

**What you practice:**
- Class toggling
- Array methods
- Clear UI state management

## Project 3: Random Quote Generator

**What to build:**
- A button to show a new random quote
- A list of quote objects
- Show quote text and author

**What you practice:**
- `Math.random()`
- Objects and arrays
- DOM text updates
