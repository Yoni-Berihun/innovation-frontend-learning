# Beginner JavaScript Projects

> Build simple interactive web pages while practicing core JavaScript skills.

## Project 1: Click Counter

**What to build:**
- A page with a button and a number display
- Each click increases the number
- A reset button clears the count

**What you practice:**
- DOM selection
- Event listeners
- Updating text content

## Project 2: Color Switcher

**What to build:**
- A button that changes the page background color
- Use an array of colors
- Show the current color name on the page

**What you practice:**
- Arrays
- Functions
- DOM updates

## Project 3: Simple Form Message

**What to build:**
- A form with a name input and a submit button
- When submitted, show a greeting message on the page
- Prevent the default form refresh behavior

**What you practice:**
- Forms and events
- `event.preventDefault()`
- Template strings
