# Advanced JavaScript Projects

> Build complete interactive apps using modern JavaScript and real data.

## Project 1: API Data Viewer

**What to build:**
- A page that fetches data from a public API
- Show results in cards or a list
- Display a loading state while data is fetched

**What you practice:**
- `fetch()` and `async` / `await`
- Error handling
- Working with JSON data

## Project 2: Search and Filter

**What to build:**
- A list of items with a search input
- Filter items as the user types
- Show matching results only

**What you practice:**
- Array `filter()`
- Input events
- Dynamic UI updates

## Project 3: Interactive Quiz

**What to build:**
- A quiz with multiple questions and answer choices
- Track the user's score
- Show a final summary at the end

**What you practice:**
- State management
- Event handling
- Dynamic content and conditional logic
