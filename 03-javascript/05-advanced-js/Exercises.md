# Exercises: Advanced JavaScript

> Practice advanced JavaScript patterns, storage, debugging, and browser APIs.

---

## 🟢 Easy Exercises

### Exercise 1.1: Debug with `console.log()`
**Objective:** Use the browser console to inspect values.

**Instructions:**
- Create a small script with variables and calculations.
- Add `console.log()` statements to show each value.
- Open the browser console and verify the output.

### Exercise 1.2: Save a Value to `localStorage`
**Objective:** Learn browser storage.

**Instructions:**
- Create an input and button.
- Save the input value to `localStorage` when the button is clicked.
- Load the saved value when the page opens.

---

## 🟡 Medium Exercises

### Exercise 2.1: Error Safe Parser
**Objective:** Practice `try` / `catch`.

**Instructions:**
- Create a function that parses JSON from a textarea.
- Use `try` / `catch` to handle invalid JSON.
- Show a friendly message if parsing fails.

### Exercise 2.2: Build a Notes Widget
**Objective:** Build a small app with storage.

**Instructions:**
- Create a textarea and save button.
- Save notes to `localStorage`.
- Display saved notes on page load.
- Allow users to clear the notes.

---

## 🔴 Challenging Exercises

### Exercise 3.1: Create a Timer App
**Objective:** Use timers and state management.

**Instructions:**
- Build a simple timer with start, stop, and reset buttons.
- Use `setInterval` to update the timer.
- Use `clearInterval` to stop it.

### Exercise 3.2: Modular Todo App
**Objective:** Organize code for a larger feature.

**Instructions:**
- Build a Todo app with add, complete, and remove items.
- Organize functions into clear smaller pieces.
- Save items to `localStorage`.
- Use a separate `utils.js` file for helper functions.
