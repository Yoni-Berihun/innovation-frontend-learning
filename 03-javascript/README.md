# ⚙️ JavaScript Essentials Track

> **Master the programming language that powers modern web pages.** This track teaches JavaScript from basic syntax to interactive DOM apps and asynchronous APIs.

---

## 📚 What You'll Learn

### Module 1: JavaScript Basics
- Variables and data types
- Operators and expressions
- Control flow (`if`, `switch`, loops)
- Functions and scope

### Module 2: DOM Manipulation
- Selecting DOM elements
- Changing page content
- Handling events
- Building interactive UI

### Module 3: ES6+ Modern JavaScript
- `let` / `const`
- Arrow functions
- Template literals
- Destructuring
- Modules

### Module 4: Asynchronous Programming
- Callbacks
- Promises
- `async` / `await`
- Fetch API and working with remote data

---

## 🎯 Track Objectives

By the end of this track, you will:

✅ Write clean JavaScript code
✅ Build interactive web pages
✅ Manipulate page content with the DOM
✅ Use modern ES6+ syntax
✅ Fetch and display data from APIs

## 💡 JavaScript Foundations

### Variables
```js
let name = "Alex";
const age = 24;
```

### Functions
```js
function greet(user) {
  return `Hello ${user}`;
}
```

### DOM Example
```js
const heading = document.querySelector("h1");
heading.textContent = "Hello JavaScript";
```

### Fetch Example
```js
fetch("https://api.example.com/data")
  .then(response => response.json())
  .then(data => console.log(data));
```
