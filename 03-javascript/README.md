# ⚙️ JavaScript Essentials Track

> **Learn JavaScript from the first line of code to real interactive web apps.** This track is designed for beginners and grows step by step into modern, advanced JavaScript.

---

## 📌 Course Outline

### 01 - JavaScript Basics
- [Start here](./01-basics/README.md)
- Learn variables, data types, functions, loops, conditions, arrays, and objects.
- Build simple JavaScript logic for the browser.

### 02 - DOM Manipulation
- [Read the module](./02-dom-manipulation/README.md)
- Learn how JavaScript can change page content and styles.
- Build interactive buttons, forms, and live updates.

### 03 - ES6+ Modern JavaScript
- [Read the module](./03-es6-plus/README.md)
- Learn modern syntax like `let`, `const`, arrow functions, destructuring, and classes.
- Write cleaner, shorter, and more powerful JavaScript.

### 04 - Asynchronous Programming
- [Read the module](./04-asynchronous/README.md)
- Learn callbacks, Promises, `async` / `await`, and API data loading.
- Build apps that fetch remote data and handle delays.

### 05 - Advanced JavaScript
- [Read the module](./05-advanced-js/README.md)
- Learn debugging, error handling, browser storage, timers, and better app structure.
- Use modern browser features to build more complete web apps.

### Projects
- [Beginner Projects](./projects/beginner)
- [Intermediate Projects](./projects/intermediate)
- [Advanced Projects](./projects/advanced)

### Resources
- [JavaScript Resources](./resources/javascript-resources.md)

## 🧠 JavaScript Learning Path

### Beginner stage
- Learn variable types, functions, and loops
- Understand how JavaScript runs in the browser
- Practice small programs and console debugging

### Intermediate stage
- Learn to read and change the DOM
- Build interactive forms and buttons
- Use modern ES6+ syntax for cleaner code

### Advanced stage
- Learn asynchronous JavaScript with `fetch`
- Build apps that use real API data
- Use classes, modules, and reusable code patterns
