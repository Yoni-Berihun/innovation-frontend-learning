# 🧪 Advanced React Exercises

## Exercise 1: Inspect a React Project

1. Open a React project folder.
2. Identify the files in `public/` and `src/`.
3. Note where the root component is defined.
4. Write down three folders you would create for a medium-sized React app.

---

## Exercise 2: Build a Deployment Checklist

Create a checklist for deploying a React app:
- [ ] Run the production build command
- [ ] Verify the output folder exists
- [ ] Confirm the host supports single-page apps
- [ ] Add any required redirects or rewrite rules
- [ ] Publish and visit the live site

---

## Exercise 3: Create a Custom Hook

Write a custom hook named `useWindowWidth` that:
- returns the current window width
- updates when the browser resizes
- cleans up the resize listener on unmount

Use the hook in a component that shows the window width on screen.
