# Troubleshooting Guide

## Common HTML Issues
- Missing `<!DOCTYPE html>` can cause weird layout behavior.
- Use valid tags and nesting.
- Always add `alt` text for images.

## Common CSS Issues
- Check selector specificity if styles do not apply.
- Use `box-sizing: border-box;` to simplify layout calculations.
- Verify linked stylesheet path in HTML.

## Common JavaScript Issues
- Use the browser console to inspect errors.
- Make sure scripts are loaded after the HTML elements they target.
- Check spelling for function names and variables.

## Common React Issues
- Remember to use `className` instead of `class`.
- Wrap JSX in a single parent element.
- Run `npm install` when cloning a project.
- Use `npm start` or `npm run dev` to launch the development server.

## Debugging Tips
- Reload the page after making code changes.
- Look for error messages in the browser console.
- Use `console.log()` to inspect values.
- Break complex problems into smaller steps.
