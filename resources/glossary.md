# Glossary of Frontend Terms

## HTML
- **HTML** — HyperText Markup Language, the structure of web pages.
- **Element** — A tag and its content, like `<div>` or `<p>`.
- **Attribute** — Extra information inside a tag, like `class="button"`.
- **Semantic HTML** — Using meaningful tags such as `<header>`, `<nav>`, `<main>`, and `<footer>`.

## CSS
- **CSS** — Cascading Style Sheets, used to style web pages.
- **Selector** — The part of CSS that chooses which elements to style.
- **Box model** — The structure of an element including margin, border, padding, and content.
- **Flexbox** — A layout system for aligning items in a row or column.
- **Grid** — A two-dimensional layout system for creating page layouts.

## JavaScript
- **Variable** — A storage name for data, created with `let`, `const`, or `var`.
- **Function** — A reusable block of code.
- **DOM** — Document Object Model, the page structure JavaScript can modify.
- **Event** — An action like a click or submit that JavaScript can respond to.
- **Promise** — A JavaScript object representing a future value.

## React
- **Component** — A reusable piece of UI.
- **Props** — Data passed from parent to child components.
- **State** — Data managed inside a component.
- **JSX** — Syntax that allows HTML-like code inside JavaScript.
- **Virtual DOM** — A lightweight copy of the real DOM used by React.
