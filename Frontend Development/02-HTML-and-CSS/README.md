# 02-HTML-and-CSS

## Concept Explanation

This module teaches the core building blocks of web pages.

- HTML defines structure with tags like headings, lists, links, forms, and tables.
- Semantic HTML uses meaningful tags so browsers and screen readers understand your content.
- CSS controls color, typography, spacing, layout, and responsive design.

### Real-world examples

- A blog article using `<article>`, `<section>`, and `<aside>`
- A navigation bar built with `<nav>` and styled with CSS
- A responsive grid of cards that rearrange on smaller screens

### Practical relevance

Understanding HTML and CSS is essential for:

- Turning designs into code
- Making pages accessible for all users
- Improving readability and maintainability
- Creating layouts that work across devices
