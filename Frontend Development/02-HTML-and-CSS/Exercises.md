# 02-HTML-and-CSS Exercises

## Easy

1. Create an HTML page for a mentor profile with:
   - `<header>` for the name and title
   - `<main>` with an introduction and a list of skills
   - `<footer>` with contact links

2. Add CSS to:
   - Set a readable font family and line height
   - Give the page a consistent color palette
   - Style links with hover effects

## Medium

1. Build a two-column layout that includes:
   - A navigation menu on the left
   - A content section on the right

2. Use CSS to make the layout responsive:
   - Stack sections in one column on smaller screens
   - Use `@media` queries and `grid` or `flexbox`

## Challenging

1. Create a landing page for a study group with:
   - A hero section
   - A features section with 3 cards
   - A signup or contact form

2. Add accessible elements such as:
   - `alt` text for images
   - clear form labels
   - keyboard-friendly focus styles
