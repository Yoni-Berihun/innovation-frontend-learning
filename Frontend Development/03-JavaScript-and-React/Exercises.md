# 03-JavaScript-and-React Exercises

## Easy

1. Add JavaScript to a page that:
   - Logs a message when the page loads
   - Changes the text of a heading when a button is clicked

2. Create a small script that:
   - Reads a value from an input
   - Displays that value in a paragraph

## Medium

1. Build a task list with JavaScript:
   - Add a task input field
   - Show the task in a list when the user submits
   - Add a button to remove tasks

2. Create a React component for a counter:
   - Show a number on screen
   - Add buttons to increase and decrease the value
   - Keep the state inside the component

## Challenging

1. Build a small React app with:
   - A list of items
   - A form to add a new item
   - A filter or search input

2. Enhance your app by:
   - Adding a clear-all button
   - Saving data to `localStorage`
