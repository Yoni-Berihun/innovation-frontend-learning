# 01-Introduction

## What is Frontend Development?

Frontend development is the part of web development that builds what users see and interact with in a browser. It includes websites and web apps made with HTML, CSS, and JavaScript.

### Beginner-friendly explanation

- HTML provides the structure of the page, like the bones of a house.
- CSS adds style, like paint, layout, and spacing.
- JavaScript adds interactivity, like clicking buttons and loading data.

### Real-world examples

- A landing page with a navigation menu
- A form where users submit their email
- A responsive profile card that looks good on phone and desktop

### Practical relevance

Learning frontend development gives you the skills to:

- Build web pages and mobile-friendly layouts
- Turn designs into working interfaces
- Create interactive features for users
- Prepare for internships and junior roles in tech
