# 01-Introduction Exercises

## Easy

1. Create a simple HTML page with:
   - A heading
   - A paragraph
   - An image
   - A link to another website

2. Add a CSS file and change:
   - The background color
   - The heading color
   - The font of the paragraph

## Medium

1. Build a mini profile card with:
   - A profile picture placeholder
   - Name and short bio
   - Contact links (email, website)

2. Make the card responsive so it looks good on mobile and desktop using:
   - `max-width`
   - `margin: auto`
   - `flexbox`

## Challenging

1. Plan a homepage for a fictional mentor program. Include:
   - A headline
   - Three benefits
   - A call to action button

2. Write a short reflection:
   - Why did you choose this layout?
   - How will users interact with this page?
