# Beginner Projects

## Project 1: Personal Profile Page

### Objective
Build a clean personal profile page using HTML and CSS.

### Requirements
- Header with name and role
- About section with a short bio
- Skills list or simple timeline
- Contact links
- Responsive layout for mobile and desktop

### Stretch Goals
- Add a photo or illustration
- Use CSS hover effects on links
- Add a footer with social links

### Suggested Improvements
- Add a color palette that matches your style
- Improve spacing with `padding` and `margin`
- Use semantic HTML tags for each section
