# Exercises: Advanced HTML

> Practice the advanced HTML topics covered in this module.

---

## 🟢 Easy Exercises

### Exercise 1.1: Build an Accessible Article Page
**Objective:** Create a page using semantic structure and accessibility features.

**Requirements:**
- Use `header`, `main`, `article`, and `footer`
- Include a page title, author, publish date, and article text
- Use `<figure>` and `<figcaption>` for one image
- Add one internal link to another section
- Add at least one `<time>` element

---

### Exercise 1.2: Add Metadata and Social Preview
**Objective:** Practice page metadata and SEO-friendly tags.

**Requirements:**
- Add `title`, `meta description`, and `viewport`
- Add Open Graph metadata (`og:title`, `og:description`, `og:image`)
- Add `favicon` link
- Add at least two keywords in the description

---

## 🟡 Medium Exercises

### Exercise 2.1: Create a Multimedia Landing Page
**Objective:** Build a page with images, video, and accessible markup.

**Requirements:**
- Add a page header and feature section
- Embed a video using `<video controls>`
- Add an image with `alt` text and width/height attributes
- Include a call-to-action button link
- Use `<section>` blocks to separate content

---

### Exercise 2.2: Build an Accessible Form Page
**Objective:** Create a page with a complete accessible form.

**Requirements:**
- Use `fieldset` and `legend`
- Use `<label>` for every input
- Add at least one `aria-label` or `aria-describedby`
- Include `required` validation attributes
- Add a submit button and an optional reset button

---

## 🔴 Challenging Exercises

### Exercise 3.1: Build a Documentation Page with Structure
**Objective:** Create a documentation or help page using advanced HTML structure.

**Requirements:**
- Add a `nav` with internal links to each section
- Use `section`, `article`, and `aside`
- Add a table of contents at the top
- Include at least one code sample using `<pre><code>`
- Add a footer with contact or navigation links

---

### Exercise 3.2: Create a Responsive Content Section
**Objective:** Build a responsive layout using HTML structure and class names.

**Requirements:**
- Create a page with a hero section, features section, and testimonial section
- Use `article` and `section` for each content block
- Add image captions
- Add semantic structure so the page is easy to read without CSS

---

### Exercise 3.3: Build an Accessible Media Gallery
**Objective:** Create a media gallery page with accessible markup.

**Requirements:**
- Use a list (`<ul>`) or grid style structure for gallery items
- Use `<figure>` and `<figcaption>` for each item
- Add descriptive `alt` text for each image
- Add a video or audio element with controls
- Add a summary section describing the gallery
